Selenium installation and Selenium Manager

WebDriver basics · Complete program, tricky exercise, and interview answers

First time writing Python?Start from zero →Read the punctuation guide ↗

The idea

Selenium’s Python bindings control a browser through WebDriver. Selenium Manager can resolve drivers automatically in a standard Selenium setup; a first run may need network access. Install a supported browser and keep its driver lifecycle owned by a fixture.

A complete program to try.

BEFORE YOU RUN

Save the entire program in test_selenium_installation_and_selenium_manager.py. Open a terminal in that file’s folder and activate your project’s virtual environment. Commands go in the terminal; the program goes in the .py file.

Install once in your activated environment: python -m pip install pytest selenium.

The Way2Python site must be running at localhost:8080/way2python. Selenium also needs an installed browser such as Chrome.

Run: python -m pytest test_selenium_installation_and_selenium_manager.py -q

On macOS/Linux outside a virtual environment use python3; on Windows use py. The beginner guide explains both.

COMPLETE PYTHON PROGRAM
import os
import pytest
from selenium import webdriver
from selenium.webdriver.common.by import By
from selenium.webdriver.support.ui import WebDriverWait
from selenium.webdriver.support import expected_conditions as EC

@pytest.fixture
def driver():
    instance = webdriver.Chrome()
    yield instance
    instance.quit()

def test_practice(driver):
    base_url = os.getenv("WAY2PYTHON_URL", "http://localhost:8080/way2python")
    driver.get(f"{base_url}/practice.html")
    driver.find_element(By.ID, "email").send_keys("learner@example.test")
    driver.find_element(By.ID, "password").send_keys("python123")
    driver.find_element(By.CSS_SELECTOR, "#login-form button[type=submit]").click()
    WebDriverWait(driver, 5).until(EC.text_to_be_present_in_element((By.ID, "login-status"), "Welcome, learner!"))
    assert driver.find_element(By.ID, "login-status").text == "Welcome, learner!"
EXPECTED RESULT
1 passed after Chrome and Selenium startup succeeds. The driver fixture quits the session.

What does Selenium Manager do, and what can still prevent startup?

It helps discover and manage browser drivers in a standard Selenium installation. An unavailable browser, proxy restrictions, incompatible environment or blocked downloads can still prevent session creation. Inspect startup evidence before changing test locators.

Which common mistake can affect this program or test?

Corporate proxies or offline environments may need explicit browser and driver configuration. Avoid obsolete executable_path constructor examples.
