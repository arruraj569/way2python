Playwright forms, selects and checkboxes

Locators & interactions · Complete program, tricky exercise, and interview answers

The idea

Use fill for text, select_option for a native select, and check for checkboxes. Verify the resulting business state after saving, rather than merely proving that a click completed.

A complete program to try.

BEFORE YOU RUN

Save the entire program in test_playwright_forms_selects_and_checkboxes.py. Open a terminal in that file’s folder and activate your project’s virtual environment. Commands go in the terminal; the program goes in the .py file.

Install once in your activated environment: python -m pip install pytest-playwright.

Install Chromium once: python -m playwright install chromium. Browser test files use fixtures supplied by the pytest plugin.

The Way2Python site must be running at localhost:8080/way2python. Selenium also needs an installed browser such as Chrome.

Run: python -m pytest test_playwright_forms_selects_and_checkboxes.py -q --base-url http://localhost:8080/way2python

On macOS/Linux outside a virtual environment use python3; on Windows use py. The beginner guide explains both.

COMPLETE PYTHON PROGRAM
from playwright.sync_api import Page, expect

def test_practice(page: Page, base_url):
    page.goto(f"{base_url}/practice.html")
    page.get_by_label("Display name").fill("Mira")
    page.get_by_label("Learning track").select_option("api")
    page.get_by_label("Email updates").check()
    page.get_by_role("button", name="Save profile", exact=True).click()
    expect(page.get_by_test_id("profile-status")).to_have_text("Profile saved: Mira · API testing · updates on")
EXPECTED RESULT
1 passed; the saved profile summary reflects all three inputs.

INTERVIEW PRACTICE · EXPLAIN THE WHY

Talk it through.

Answer in your own words first. Then check the explanation and connect it to the programs above.

Why prefer check() over click() when a checkbox must be selected?

check() expresses the desired checked state and leaves an already checked checkbox checked. A click toggles its current state, which may unintentionally turn it off. Also verify the saved business outcome.

Which common mistake can affect this program or test?

A native select and a custom dropdown have different interaction models. Locate custom options by their actual roles.
