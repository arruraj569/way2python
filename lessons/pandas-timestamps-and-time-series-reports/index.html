pandas timestamps and time-series reports

pandas for automation · Complete program, tricky exercise, and interview answers

First time writing Python?Start from zero →Read the punctuation guide ↗

The idea

Parse timestamps with explicit timezone handling and summarize them at the interval your question requires. Time-series analysis can reveal changes in failure frequency or test duration; compare equivalent populations across periods.

A complete program to try.

BEFORE YOU RUN

Save the entire program in pandas_timestamps_and_time_series_reports.py. Open a terminal in that file’s folder and activate your project’s virtual environment. Commands go in the terminal; the program goes in the .py file.

Install once in your activated environment: python -m pip install pandas.

Run: python pandas_timestamps_and_time_series_reports.py

On macOS/Linux outside a virtual environment use python3; on Windows use py. The beginner guide explains both.

COMPLETE PYTHON PROGRAM
import pandas as pd
frame = pd.DataFrame({"time": ["2026-10-12T10:00:00Z", "2026-10-12T11:00:00Z"],
                      "failures": [2, 3]})
frame["time"] = pd.to_datetime(frame["time"], utc=True)
daily = frame.set_index("time")["failures"].resample("D").sum()
print(daily.iloc[0])
EXPECTED RESULT
5

INTERVIEW PRACTICE · EXPLAIN THE WHY

Talk it through.

Answer in your own words first. Then check the explanation and connect it to the programs above.

Why can daily counts change when timestamps are converted to a business timezone?

The same instant can belong to different calendar dates in different timezones. Convert or group according to the intended reporting timezone. Treat tz_localize, which assigns an interpretation, separately from tz_convert, which converts an aware instant.

Which common mistake can affect this program or test?

A higher failure count may reflect more tests being run. Compare rates and denominators too.
