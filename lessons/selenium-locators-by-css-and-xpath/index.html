Selenium locators: By, CSS and XPath

WebDriver basics · Complete program, tricky exercise, and interview answers

First time writing Python?Start from zero →Read the punctuation guide ↗

The idea

Use By with a stable ID, name, CSS selector, or narrowly scoped XPath. Prefer a selector tied to a real interface contract rather than a deep DOM path. find_elements returns a list, which may be empty.

A complete program to try.

BEFORE YOU RUN

Save the entire program in test_selenium_locators_by_css_and_xpath.py. Open a terminal in that file’s folder and activate your project’s virtual environment. Commands go in the terminal; the program goes in the .py file.

Install once in your activated environment: python -m pip install pytest selenium.

The Way2Python site must be running at localhost:8080/way2python. Selenium also needs an installed browser such as Chrome.

Run: python -m pytest test_selenium_locators_by_css_and_xpath.py -q

On macOS/Linux outside a virtual environment use python3; on Windows use py. The beginner guide explains both.

COMPLETE PYTHON PROGRAM
import os
import pytest
from selenium import webdriver
from selenium.webdriver.common.by import By
from selenium.webdriver.support.ui import WebDriverWait
from selenium.webdriver.support import expected_conditions as EC

@pytest.fixture
def driver():
    instance = webdriver.Chrome()
    yield instance
    instance.quit()

def test_practice(driver):
    base_url = os.getenv("WAY2PYTHON_URL", "http://localhost:8080/way2python")
    driver.get(f"{base_url}/practice.html")
    driver.find_element(By.ID, "email").send_keys("learner@example.test")
    driver.find_element(By.ID, "password").send_keys("python123")
    driver.find_element(By.CSS_SELECTOR, "#login-form button[type=submit]").click()
    WebDriverWait(driver, 5).until(EC.text_to_be_present_in_element((By.ID, "login-status"), "Welcome, learner!"))
    assert driver.find_element(By.ID, "login-status").text == "Welcome, learner!"

Talk it through.

Answer in your own words first. Then check the explanation and connect it to the programs above.

How do find_element and find_elements differ when nothing matches?

find_element raises NoSuchElementException, while find_elements returns an empty list. The latter can be useful for collection checks, but indexing its first entry without checking recreates a different failure.

Which common mistake can affect this program or test?

A locator that matches several elements may use the wrong control. Check uniqueness and scope.
