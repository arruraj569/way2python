The idea

The interactive shell is useful for quick experiments. Integers represent whole numbers, floats represent approximate real values, / produces true division, // performs floor division, and % gives the remainder. Use round() for display rather than assuming decimal floats are exact.

A complete program to try.

BEFORE YOU RUN

Save the entire program in python_idle_and_exploring_number_operations.py. Open a terminal in that file’s folder and activate your project’s virtual environment. Commands go in the terminal; the program goes in the .py file.

This program uses only Python’s standard library; no extra package is needed.

Run: python python_idle_and_exploring_number_operations.py

On macOS/Linux outside a virtual environment use python3; on Windows use py. The beginner guide explains both.

INTERVIEW PRACTICE · EXPLAIN THE WHY

Talk it through.

Answer in your own words first. Then check the explanation and connect it to the programs above.

Why is -7 // 3 equal to -3 rather than -2?

Floor division rounds toward negative infinity. The quotient and remainder obey a = (a // b) * b + (a % b). Ordinary binary floating-point arithmetic also cannot represent every decimal exactly.

Which common mistake can affect this program or test?

Floor division rounds down, including for negative values. For currency, learn decimal.Decimal.
