NumPy reshape, axes and aggregations

NumPy foundations · Complete program, tricky exercise, and interview answers

First time writing Python?Start from zero →Read the punctuation guide ↗

The idea

reshape changes an array’s interpretation without changing its element count. An aggregation axis specifies which dimension is collapsed. For a test-by-browser matrix, axis=0 can summarize browsers and axis=1 can summarize each test.

A complete program to try.

BEFORE YOU RUN

Save the entire program in numpy_reshape_axes_and_aggregations.py. Open a terminal in that file’s folder and activate your project’s virtual environment. Commands go in the terminal; the program goes in the .py file.

Install once in your activated environment: python -m pip install numpy.

Run: python numpy_reshape_axes_and_aggregations.py

On macOS/Linux outside a virtual environment use python3; on Windows use py. The beginner guide explains both.

import numpy as np
values = np.array([[1, 2, 3], [4, 5, 6]])
print(values.sum(axis=0).tolist())
print(values.sum(axis=1).tolist())
print(values.sum(axis=1, keepdims=True).shape)

INTERVIEW PRACTICE · EXPLAIN THE WHY

Talk it through.

Answer in your own words first. Then check the explanation and connect it to the programs above.

What does an aggregation axis identify, and why use keepdims?

It identifies the dimension being collapsed. keepdims retains that dimension with length one, which can make intended subsequent broadcasting clearer. Name what each row and column represents before choosing the axis.

Which common mistake can affect this program or test?

A reshape cannot invent or remove elements. Explain why a six-element array cannot reshape to (2, 4).
