pandas missing data, duplicates and dtypes

pandas for automation · Complete program, tricky exercise, and interview answers

First time writing Python?Start from zero →Read the punctuation guide ↗

The idea

Profile missing values and duplicates before cleaning. Nullable dtypes preserve missingness without forcing everything into an unsuitable type. A cleaning decision should follow the meaning of a column, not merely make an error disappear.

A complete program to try.

BEFORE YOU RUN

Save the entire program in pandas_missing_data_duplicates_and_dtypes.py. Open a terminal in that file’s folder and activate your project’s virtual environment. Commands go in the terminal; the program goes in the .py file.

Install once in your activated environment: python -m pip install pandas.

Run: python pandas_missing_data_duplicates_and_dtypes.py

On macOS/Linux outside a virtual environment use python3; on Windows use py. The beginner guide explains both.

COMPLETE PYTHON PROGRAM
import pandas as pd
frame = pd.DataFrame({"name": ["Mira", "Mira", "Arun"],
                      "duration": [1.0, 1.0, None]})
unique = frame.drop_duplicates()
print(len(unique))
print(unique["duration"].isna().sum())
print(unique["duration"].fillna(0).tolist())
EXPECTED RESULT

1
[1.0, 0.0]

TRICKY PYTHON PROGRAM
import pandas as pd
values = pd.Series([1, pd.NA], dtype="Int64")
print(values.isna().tolist())
try:
    bool(pd.NA)
except TypeError:
    print("missing truth value is ambiguous")
print(values.fillna(0).tolist())

INTERVIEW PRACTICE · EXPLAIN THE WHY

Talk it through.

Answer in your own words first. Then check the explanation and connect it to the programs above.

Why can testing a nullable missing value in a plain if statement fail?

pd.NA represents unknown data whose boolean truth is ambiguous. Use isna/notna and an explicit missing-data rule. Nullable dtypes preserve missingness, so replacing it with zero is a domain choice rather than a neutral fix.

Which common mistake can affect this program or test?

Dropping rows or filling with zero can bias a model or conceal an instrumentation defect.
