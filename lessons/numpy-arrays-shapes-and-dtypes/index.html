NumPy arrays, shapes and dtypes

NumPy foundations · Complete program, tricky exercise, and interview answers

First time writing Python?Start from zero →Read the punctuation guide ↗

The idea

NumPy stores numerical data in ndarrays with a shape and dtype. A table of features can be represented as a two-dimensional array: rows are examples and columns are features. Inspect these properties before performing calculations.

A complete program to try.

BEFORE YOU RUN

Save the entire program in numpy_arrays_shapes_and_dtypes.py. Open a terminal in that file’s folder and activate your project’s virtual environment. Commands go in the terminal; the program goes in the .py file.

Install once in your activated environment: python -m pip install numpy.

Run: python numpy_arrays_shapes_and_dtypes.py

On macOS/Linux outside a virtual environment use python3; on Windows use py. The beginner guide explains both.

numpy_arrays_shapes_and_dtypes.pyDownload program ↓
COMPLETE PYTHON PROGRAM
import numpy as np
features = np.array([[1.2, 3.0], [0.8, 2.0]], dtype=np.float64)
print(features.shape, features.ndim)
print(features.dtype)
print(features.tolist())
EXPECTED RESULT
(2, 2) 2
float64
[[1.2, 3.0], [0.8, 2.0]]

Talk it through.

Answer in your own words first. Then check the explanation and connect it to the programs above.

How does adding Python lists differ from adding compatible NumPy arrays?

Lists concatenate; NumPy arrays perform elementwise numerical addition subject to broadcasting. dtype controls representation, and converting floating values into an integer array discards their fractional parts.

Which common mistake can affect this program or test?

Choosing an integer dtype for fractional values can discard information. dtype is part of the data contract.
