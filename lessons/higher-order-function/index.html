Higher Order Function

Functional Python · Complete program, tricky exercise, and interview answers

The idea

Functions are values: you can pass them as arguments or return them. A higher-order function uses that capability to separate an operation from the data it processes. This is the basis of callbacks, sort keys, and decorators.

A complete program to try.

BEFORE YOU RUN

Save the entire program in higher_order_function.py. Open a terminal in that file’s folder and activate your project’s virtual environment. Commands go in the terminal; the program goes in the .py file.

This program uses only Python’s standard library; no extra package is needed.

Run: python higher_order_function.py

On macOS/Linux outside a virtual environment use python3; on Windows use py. The beginner guide explains both.

COMPLETE PYTHON PROGRAM
def apply_to_all(operation, values):
    return [operation(value) for value in values]

def milliseconds(seconds):
    return int(seconds * 1000)

print(apply_to_all(milliseconds, [0.2, 0.5, 1.0]))
EXPECTED RESULT
[200, 500, 1000]

TRICKY PYTHON PROGRAM
def twice(function, value):
    return function(function(value))

print(twice(lambda value: value + 1, 3))
print(twice(str.upper, "python"))

Talk it through.

Answer in your own words first. Then check the explanation and connect it to the programs above.

What makes a function higher-order?

It accepts a function or returns a function. This allows behavior to be supplied without hardcoding it. The callable still needs a compatible input and output contract.

Which common mistake can affect this program or test?

Pass milliseconds to supply the function; milliseconds() calls it immediately.
