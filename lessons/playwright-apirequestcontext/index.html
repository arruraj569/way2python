The idea

Playwright can make HTTP calls directly through an APIRequestContext. This is useful for preparing test data and checking an API alongside browser journeys. Decide whether a request context should share browser cookies or remain independent.

A complete program to try.

BEFORE YOU RUN

Save the entire program in playwright_apirequestcontext.py. Open a terminal in that file’s folder and activate your project’s virtual environment. Commands go in the terminal; the program goes in the .py file.

Install once in your activated environment: python -m pip install playwright.

Start the local API service first: python mock_api.py --port 8765 from the unzipped practice kit. Keep that terminal running, and run the program in a second activated terminal.

Run: python playwright_apirequestcontext.py

On macOS/Linux outside a virtual environment use python3; on Windows use py. The beginner guide explains both.

playwright_apirequestcontext.pyDownload program ↓
COMPLETE PYTHON PROGRAM
from playwright.sync_api import sync_playwright
with sync_playwright() as playwright:
    client = playwright.request.new_context(base_url="http://127.0.0.1:8765",
        extra_http_headers={"Authorization": "Bearer demo-token"})
    try:
        response = client.get("/users", timeout=5000)
        assert response.status == 200
        assert isinstance(response.json()["items"], list)
        print("Playwright API check passed")
    finally:
        client.dispose()
EXPECTED RESULT
Playwright API check passed (no browser launch is needed).

INTERVIEW PRACTICE · EXPLAIN THE WHY

Talk it through.

Answer in your own words first. Then check the explanation and connect it to the programs above.

What two ownership decisions matter for a Playwright API request context?

Decide whether it shares browser cookies or is created independently, and ensure its resources are disposed at the correct lifecycle boundary. Also remember that Playwright timeouts are milliseconds rather than Requests seconds.

Which common mistake can affect this program or test?

Playwright timeouts use milliseconds; Requests timeouts use seconds. Dispose request contexts to release resources.
