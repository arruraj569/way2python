The idea

Install a supported Python 3 release, verify which interpreter your terminal uses, and create a virtual environment for each project. The environment keeps dependencies separate. The commands below use Python 3.12+ and work on macOS/Linux; on Windows use py and the Scripts activation path.

A complete program to try.

BEFORE YOU RUN

Save the entire program in python_setup.py. Open a terminal in that file’s folder and activate your project’s virtual environment. Commands go in the terminal; the program goes in the .py file.

This program uses only Python’s standard library; no extra package is needed.

Run: python python_setup.py

On macOS/Linux outside a virtual environment use python3; on Windows use py. The beginner guide explains both.

python_setup.pyDownload program ↓
COMPLETE PYTHON PROGRAM
import sys
print("Hello, Python!")
print("Python major version:", sys.version_info.major)
print("Interpreter:", sys.executable)
print("Virtual environment:", sys.prefix != sys.base_prefix)
EXPECTED RESULT
Hello, Python!
Python major version: 3
Interpreter: your active Python path
Virtual environment: True inside .venv; otherwise False
Installation and runner commands
TERMINAL / REFERENCE
python3 --version
python3 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
python -c "import sys; print(sys.executable)"

The last command prints your project’s .venv interpreter path.

Read it step by step.

Read from the top. A function or class body does not run just because you defined it; look for the call, or let pytest call a test function.

  1. Line 1: Import sys. This makes the named library tools available; third-party packages must be installed first.
  2. Line 2: Print 'Hello, Python!' to the terminal. print displays values and returns None.
  3. Line 3: Print 'Python major version:', sys.version_info.major to the terminal. print displays values and returns None.
  4. Line 4: Print 'Interpreter:', sys.executable to the terminal. print displays values and returns None.
  5. Line 5: Print 'Virtual environment:', sys.prefix != sys.base_prefix to the terminal. print displays values and returns None.
YOUR TURN

Make it yours.

Create a new folder and environment. On Windows use py -m venv .venv and .venv\Scripts\Activate.ps1 in PowerShell.

INTERVIEW PRACTICE · EXPLAIN THE WHY

Talk it through.

Answer in your own words first. Then check the explanation and connect it to the programs above.

Why might pip report a successful install while import still fails?

pip may belong to a different interpreter or environment. Compare sys.executable with the editor interpreter and use python -m pip from the interpreter that will run the program.

Which common mistake can affect this program or test?

Choose the same environment in your editor. A package installed into another interpreter will still appear missing.
