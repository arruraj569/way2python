Context managers and cleanup

Reliability & concurrency · Complete program, tricky exercise, and interview answers

First time writing Python?Start from zero →Read the punctuation guide ↗

The idea

A context manager defines entry and exit behavior for a with block. Use it to release files, clients, and other resources even when an exception occurs. Cleanup belongs close to the resource’s lifetime.

A complete program to try.

BEFORE YOU RUN

Save the entire program in context_managers_and_cleanup.py. Open a terminal in that file’s folder and activate your project’s virtual environment. Commands go in the terminal; the program goes in the .py file.

This program uses only Python’s standard library; no extra package is needed.

Run: python context_managers_and_cleanup.py

On macOS/Linux outside a virtual environment use python3; on Windows use py. The beginner guide explains both.

COMPLETE PYTHON PROGRAM
from contextlib import contextmanager
@contextmanager
def session_label():
    print("setup")
    try:
        yield "isolated session"
    finally:
        print("cleanup")

with session_label() as label:
    print(label)
EXPECTED RESULT
setup
isolated session
cleanup

TRICKY PYTHON PROGRAM
from contextlib import contextmanager
@contextmanager
def resource():
    print("open")
    try: yield
    finally: print("close")

try:
    with resource():
        raise ValueError("broken")
except ValueError:
    print("failure preserved")

INTERVIEW PRACTICE · EXPLAIN THE WHY

Talk it through.

Answer in your own words first. Then check the explanation and connect it to the programs above.

Can cleanup run when the body of a with block fails?

Yes. A correctly implemented context manager executes exit handling as the block unwinds. It may suppress an exception only if its contract deliberately requests that behavior; normal cleanup should preserve the failure.

Which common mistake can affect this program or test?

Yield only once in a generator-based context manager. Do not accidentally swallow the block’s exception.
