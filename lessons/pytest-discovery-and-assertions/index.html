pytest discovery and assertions

Testing foundations · Complete program, tricky exercise, and interview answers

First time writing Python?Start from zero →Read the punctuation guide ↗

The idea

pytest discovers appropriately named files and functions. Plain assert statements produce useful comparison output. Keep a test focused on a behavior and make its setup, action, and checks easy to locate.

A complete program to try.

BEFORE YOU RUN

Save the entire program in test_pytest_discovery_and_assertions.py. Open a terminal in that file’s folder and activate your project’s virtual environment. Commands go in the terminal; the program goes in the .py file.

Install once in your activated environment: python -m pip install pytest.

Run: python -m pytest test_pytest_discovery_and_assertions.py -q

On macOS/Linux outside a virtual environment use python3; on Windows use py. The beginner guide explains both.

COMPLETE PYTHON PROGRAM
def normalized_name(value):
    return value.strip().lower()

def test_normalized_name():
    actual = normalized_name("  LOGIN  ")
    assert actual == "login"

def test_empty_name():
    assert normalized_name("   ") == ""
EXPECTED RESULT
Save as test_names.py; python -m pytest -q reports 2 passed.

Read it step by step.

Read from the top. A function or class body does not run just because you defined it; look for the call, or let pytest call a test function.

  1. Line 1: Define normalized_name(value). Its body runs when called, rather than just because the definition was read.
  2. Line 4: Define test_normalized_name(). Its body runs when called by pytest, which supplies fixture arguments.
  3. Line 8: Define test_empty_name(). Its body runs when called by pytest, which supplies fixture arguments.
  4. Line 5: Bind actual to the result of normalized_name(' LOGIN '). Assignment gives a value a name; it does not automatically copy a nested object.
  5. Line 6: Check actual == 'login'. The program continues if this is true and raises AssertionError if it is false.

INTERVIEW PRACTICE · EXPLAIN THE WHY

Talk it through.

Answer in your own words first. Then check the explanation and connect it to the programs above.

Does returning False from a function make pytest fail it?

Tests should use assertions or raise an error. pytest does not use a returned boolean as an oracle, and default discovery also expects test-style names. A function that returns False may not be collected at all.

Which common mistake can affect this program or test?

A function that prints a result without asserting it can pass even when the result is wrong.
