scikit-learn pipelines and data leakage

AI & machine learning · Complete program, tricky exercise, and interview answers

First time writing Python?Start from zero →Read the punctuation guide ↗

The idea

Fit preprocessing only on training data. A Pipeline couples transformations with an estimator so cross-validation applies them consistently. Leakage occurs when information from evaluation data influences training or feature preparation.

A complete program to try.

COMPLETE PYTHON PROGRAM
from sklearn.datasets import load_iris
from sklearn.model_selection import train_test_split
from sklearn.pipeline import make_pipeline
from sklearn.preprocessing import StandardScaler
from sklearn.linear_model import LogisticRegression
data = load_iris()
train_x, test_x, train_y, test_y = train_test_split(
    data.data, data.target, test_size=0.2, random_state=42, stratify=data.target)
model = make_pipeline(StandardScaler(), LogisticRegression(max_iter=300))
model.fit(train_x, train_y)
predictions = model.predict(test_x)
assert predictions.shape == test_y.shape
print("Held-out predictions:", len(predictions))
EXPECTED RESULT
Held-out predictions: 30

INTERVIEW PRACTICE · EXPLAIN THE WHY

Talk it through.

Answer in your own words first. Then check the explanation and connect it to the programs above.

What leaks when a scaler is fit before the train/test split?

Evaluation values influence preprocessing statistics used by the model. Fit transformations on training data only, ideally inside a Pipeline so each cross-validation fold learns them independently. A final held-out set should remain untouched during tuning.

Which common mistake can affect this program or test?

Do not tune repeatedly against the final test set. Use cross-validation for model selection.
