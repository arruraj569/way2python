NumPy vectorization and broadcasting

NumPy foundations · Complete program, tricky exercise, and interview answers

First time writing Python?Start from zero →Read the punctuation guide ↗

The idea

Vectorized operations apply compiled array operations without an explicit Python loop. Broadcasting aligns compatible shapes, allowing one mean per feature to be subtracted from every row. Inspect shapes before assuming an operation means what you intend.

A complete program to try.

BEFORE YOU RUN

Save the entire program in numpy_vectorization_and_broadcasting.py. Open a terminal in that file’s folder and activate your project’s virtual environment. Commands go in the terminal; the program goes in the .py file.

Install once in your activated environment: python -m pip install numpy.

Run: python numpy_vectorization_and_broadcasting.py

On macOS/Linux outside a virtual environment use python3; on Windows use py. The beginner guide explains both.

COMPLETE PYTHON PROGRAM
import numpy as np
samples = np.array([[1.0, 10.0], [3.0, 20.0]])
feature_means = samples.mean(axis=0)
centered = samples - feature_means
print(feature_means.tolist())
print(centered.tolist())
EXPECTED RESULT
[2.0, 15.0]
[[-1.0, -5.0], [1.0, 5.0]]

INTERVIEW PRACTICE · EXPLAIN THE WHY

Talk it through.

Answer in your own words first. Then check the explanation and connect it to the programs above.

Why can adding two apparently three-value arrays produce nine values?

Broadcasting aligns dimensions from the right. Shapes (3,) and (3, 1) broadcast to (3, 3), so the operation produces all row/column combinations. Validate shape meaning, not only whether the operation succeeds.

Which common mistake can affect this program or test?

Broadcasting can succeed while doing the wrong conceptual operation. Verify row/column meaning explicitly.
