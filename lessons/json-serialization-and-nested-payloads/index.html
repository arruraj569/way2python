JSON serialization and nested payloads

Files & structured data · Complete program, tricky exercise, and interview answers

First time writing Python?Start from zero →Read the punctuation guide ↗

The idea

json.dumps serializes a Python value to text; json.loads parses JSON text. API payloads often combine nested dictionaries and lists. Distinguish missing keys from explicit null values, which parse as None.

A complete program to try.

BEFORE YOU RUN

Save the entire program in json_serialization_and_nested_payloads.py. Open a terminal in that file’s folder and activate your project’s virtual environment. Commands go in the terminal; the program goes in the .py file.

This program uses only Python’s standard library; no extra package is needed.

Run: python json_serialization_and_nested_payloads.py

On macOS/Linux outside a virtual environment use python3; on Windows use py. The beginner guide explains both.

json_serialization_and_nested_payloads.pyDownload program ↓
COMPLETE PYTHON PROGRAM
import json
payload = {"user": {"name": "Mira", "roles": ["reader"]}}
text = json.dumps(payload, sort_keys=True)
restored = json.loads(text)
print(restored["user"]["roles"][0])
print(restored == payload)
EXPECTED RESULT
reader
True

INTERVIEW PRACTICE · EXPLAIN THE WHY

Talk it through.

Answer in your own words first. Then check the explanation and connect it to the programs above.

Does a JSON round trip preserve every Python type exactly?

No. JSON has its own type system: object keys are strings, arrays decode as lists, and tuples are encoded as arrays. Datetimes, sets and arbitrary classes need deliberate conversion.

Which common mistake can affect this program or test?

JSON object keys are strings. datetime, set, and many NumPy values need deliberate conversion before serialization.
