The idea

Save a program in a .py file and run it with the interpreter. print() shows a value; assert compares reality with an expectation. Python uses indentation to group statements, so consistent spacing is part of the program.

A complete program to try.

BEFORE YOU RUN

Save the entire program in first_code_in_python.py. Open a terminal in that file’s folder and activate your project’s virtual environment. Commands go in the terminal; the program goes in the .py file.

This program uses only Python’s standard library; no extra package is needed.

Run: python first_code_in_python.py

On macOS/Linux outside a virtual environment use python3; on Windows use py. The beginner guide explains both.

first_code_in_python.pyDownload program ↓
COMPLETE PYTHON PROGRAM
message = "Hello, automation!"
print(message)
assert message.startswith("Hello")
EXPECTED RESULT
Hello, automation!

Read it step by step.

Read from the top. A function or class body does not run just because you defined it; look for the call, or let pytest call a test function.

  1. Line 1: Bind message to the result of 'Hello, automation!'. Assignment gives a value a name; it does not automatically copy a nested object.
  2. Line 2: Print message to the terminal. print displays values and returns None.
  3. Line 3: Check message.startswith('Hello'). The program continues if this is true and raises AssertionError if it is false.

Talk it through.

Answer in your own words first. Then check the explanation and connect it to the programs above.

What is the difference between printing a value and returning it?

print() writes text to an output stream and returns None. return hands a value back to the caller of a function. A reusable calculation should normally return its result so a test can assert it.

Which common mistake can affect this program or test?

Do not name your file json.py, requests.py, or playwright.py; it can hide the library you want to import.
