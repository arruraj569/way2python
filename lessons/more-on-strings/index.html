More on Strings

Values & strings · Complete program, tricky exercise, and interview answers

The idea

Normalize text with strip(), split(), join(), and replace(). These operations return new strings, which is useful when cleaning CSV fields or building assertion messages. Preserve the original value when whitespace or casing is part of the contract.

A complete program to try.

BEFORE YOU RUN

Save the entire program in more_on_strings.py. Open a terminal in that file’s folder and activate your project’s virtual environment. Commands go in the terminal; the program goes in the .py file.

This program uses only Python’s standard library; no extra package is needed.

Run: python more_on_strings.py

On macOS/Linux outside a virtual environment use python3; on Windows use py. The beginner guide explains both.

COMPLETE PYTHON PROGRAM
raw = "  smoke, api, browser  "
tags = [tag.strip() for tag in raw.strip().split(",")]
print(tags)
print(" | ".join(tags))
print("test_login.py".removesuffix(".py"))

INTERVIEW PRACTICE · EXPLAIN THE WHY

Talk it through.

Answer in your own words first. Then check the explanation and connect it to the programs above.

Does strip(".txt") remove the exact suffix .txt?

No. strip treats its argument as a set of characters to remove repeatedly from both ends. removesuffix removes a particular suffix when present; removeprefix handles the corresponding prefix.

Which common mistake can affect this program or test?

Calling strip() without storing the return value leaves the original string unchanged.
