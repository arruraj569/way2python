pandas Series and DataFrames

pandas for automation · Complete program, tricky exercise, and interview answers

First time writing Python?Start from zero →Read the punctuation guide ↗

The idea

A Series is a labeled one-dimensional value collection; a DataFrame is a labeled table. pandas is useful for test-result analysis, CSV data preparation, and feature tables. Inspect columns and dtypes before transforming imported data.

A complete program to try.

BEFORE YOU RUN

Save the entire program in pandas_series_and_dataframes.py. Open a terminal in that file’s folder and activate your project’s virtual environment. Commands go in the terminal; the program goes in the .py file.

Install once in your activated environment: python -m pip install pandas.

Run: python pandas_series_and_dataframes.py

On macOS/Linux outside a virtual environment use python3; on Windows use py. The beginner guide explains both.

COMPLETE PYTHON PROGRAM
import pandas as pd
results = pd.DataFrame({"test": ["login", "search"],
                        "passed": [True, False], "seconds": [1.2, 0.8]})
print(results.shape)
print(results["test"].tolist())
print(results["seconds"].mean())
EXPECTED RESULT
(2, 3)
['login', 'search']
1.0

TRICKY PYTHON PROGRAM
import pandas as pd
left = pd.Series([1, 2], index=["a", "b"])
right = pd.Series([10, 20], index=["b", "a"])
print((left + right).to_dict())
print((left.to_numpy() + right.to_numpy()).tolist())

INTERVIEW PRACTICE · EXPLAIN THE WHY

Talk it through.

Answer in your own words first. Then check the explanation and connect it to the programs above.

Why can Series arithmetic differ from adding their underlying arrays?

pandas aligns by index labels, while the arrays combine positional entries. Alignment is valuable but can surprise you if labels differ or are duplicated. Decide whether labels or positions define the intended relationship.

Which common mistake can affect this program or test?

pandas aligns data by labels. An index is not automatically a unique row identifier.
