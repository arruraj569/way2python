Selenium frames and returning to default content

Interactions · Complete program, tricky exercise, and interview answers

First time writing Python?Start from zero →Read the punctuation guide ↗

The idea

Switch the driver into an iframe before finding its elements. Return to default_content afterward so future interactions target the main page. A readiness condition can both wait for and select a frame.

A complete program to try.

BEFORE YOU RUN

Save the entire program in test_selenium_frames_and_returning_to_default_content.py. Open a terminal in that file’s folder and activate your project’s virtual environment. Commands go in the terminal; the program goes in the .py file.

Install once in your activated environment: python -m pip install pytest selenium.

The Way2Python site must be running at localhost:8080/way2python. Selenium also needs an installed browser such as Chrome.

Run: python -m pytest test_selenium_frames_and_returning_to_default_content.py -q

On macOS/Linux outside a virtual environment use python3; on Windows use py. The beginner guide explains both.

COMPLETE PYTHON PROGRAM
import os
import pytest
from selenium import webdriver
from selenium.webdriver.common.by import By
from selenium.webdriver.support.ui import WebDriverWait
from selenium.webdriver.support import expected_conditions as EC

@pytest.fixture
def driver():
    instance = webdriver.Chrome()
    yield instance
    instance.quit()

def test_practice(driver):
    base_url = os.getenv("WAY2PYTHON_URL", "http://localhost:8080/way2python")
    driver.get(f"{base_url}/practice.html")
    WebDriverWait(driver, 5).until(EC.frame_to_be_available_and_switch_to_it((By.ID, "practice-frame")))
    driver.find_element(By.ID, "frame-email").send_keys("mira@example.test")
    driver.find_element(By.ID, "frame-save").click()
    assert driver.find_element(By.ID, "frame-status").text == "Saved: mira@example.test"
    driver.switch_to.default_content()
    assert driver.find_element(By.ID, "task-table").is_displayed()
EXPECTED RESULT
1 passed inside the iframe and then in the main document.

TRICKY PYTHON PROGRAM
scope = "main"
try:
    scope = "frame"
    raise ValueError("check failed")
except ValueError:
    print("failure in:", scope)
finally:
    scope = "main"
print("restored:", scope)

INTERVIEW PRACTICE · EXPLAIN THE WHY

Talk it through.

Answer in your own words first. Then check the explanation and connect it to the programs above.

How can a frame failure break later main-page interactions?

The driver can remain in the frame context. Restore default_content in finally when subsequent main-document work is required. Otherwise a correct main-page selector may appear not to exist.

Which common mistake can affect this program or test?

A driver left in a frame may report main-page elements as missing.
