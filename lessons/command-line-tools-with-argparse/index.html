Command-line tools with argparse

Configuration & tools · Complete program, tricky exercise, and interview answers

First time writing Python?Start from zero →Read the punctuation guide ↗

The idea

argparse handles named options, types, defaults, and generated help. A small CLI makes an automation task repeatable without modifying source code. Separate argument parsing from the function that does the work.

A complete program to try.

BEFORE YOU RUN

Save the entire program in command_line_tools_with_argparse.py. Open a terminal in that file’s folder and activate your project’s virtual environment. Commands go in the terminal; the program goes in the .py file.

This program uses only Python’s standard library; no extra package is needed.

Run: python command_line_tools_with_argparse.py

On macOS/Linux outside a virtual environment use python3; on Windows use py. The beginner guide explains both.

COMPLETE PYTHON PROGRAM
import argparse
parser = argparse.ArgumentParser(description="Select a test run")
parser.add_argument("--browser", choices=["chromium", "firefox"], default="chromium")
parser.add_argument("--workers", type=int, default=1)
args = parser.parse_args([])  # Replace [] with no argument for real CLI input.
print(args.browser, args.workers)
EXPECTED RESULT
chromium 1

INTERVIEW PRACTICE · EXPLAIN THE WHY

Talk it through.

Answer in your own words first. Then check the explanation and connect it to the programs above.

Does type=int in argparse validate that a worker count is positive?

It validates conversion to an integer, not the domain rule. Add an explicit positive-value check or a custom argument type. argparse choices handles a finite declared set of allowed values.

Which common mistake can affect this program or test?

A numeric type converts input but does not validate business bounds such as a positive worker count.
