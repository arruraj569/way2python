Selenium Grid, browser options and parallel execution

Reliable suites · Complete program, tricky exercise, and interview answers

First time writing Python?Start from zero →Read the punctuation guide ↗

The idea

Grid routes WebDriver sessions to remote browsers. Browser options define capabilities; the fixture still owns the session’s lifetime. Independent tests need independent drivers and unique data when run concurrently.

A complete program to try.

BEFORE YOU RUN

Save the entire program in selenium_grid_browser_options_and_parallel_execution.py. Open a terminal in that file’s folder and activate your project’s virtual environment. Commands go in the terminal; the program goes in the .py file.

Install once in your activated environment: python -m pip install selenium.

The Way2Python site must be running at localhost:8080/way2python. Selenium also needs an installed browser such as Chrome.

Run: python selenium_grid_browser_options_and_parallel_execution.py

On macOS/Linux outside a virtual environment use python3; on Windows use py. The beginner guide explains both.

COMPLETE PYTHON PROGRAM
import os
from selenium import webdriver
from selenium.webdriver.common.by import By
from selenium.webdriver.support.ui import WebDriverWait
from selenium.webdriver.support import expected_conditions as EC

options = webdriver.ChromeOptions()
options.add_argument("--headless=new")
grid_url = os.getenv("SELENIUM_GRID_URL")
driver = (webdriver.Remote(command_executor=grid_url, options=options)
          if grid_url else webdriver.Chrome(options=options))
try:
    base_url = os.getenv("WAY2PYTHON_URL", "http://localhost:8080/way2python")
    driver.get(f"{base_url}/practice.html")
    heading = WebDriverWait(driver, 5).until(EC.visibility_of_element_located((By.TAG_NAME, "h1")))
    assert heading.text == "A small lab. Real browser skills."
    print("Browser check passed")
finally:
    driver.quit()
EXPECTED RESULT
Browser check passed. Runs locally by default; set SELENIUM_GRID_URL and a node-reachable WAY2PYTHON_URL for a configured Grid.

from selenium import webdriver
options = webdriver.ChromeOptions()

# Requires your running Grid endpoint:

try:
    driver.get("http://YOUR-APP.example/")
    print(driver.title)
finally:
    driver.quit()

Pattern only: requires a running Grid and an application reachable from its browser nodes.

INTERVIEW PRACTICE · EXPLAIN THE WHY

Talk it through.

Answer in your own words first. Then check the explanation and connect it to the programs above.

Which machine does localhost identify when a Grid browser navigates to an application?

It identifies the browser node’s own host or container, not necessarily the test runner. Configure an application address reachable from the remote browser environment, and keep one independent driver session per test.

Which common mistake can affect this program or test?

localhost inside a remote browser refers to its host, not your laptop. Configure a reachable application URL.
