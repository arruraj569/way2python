SQLite and parameterized SQL

Files & structured data · Complete program, tricky exercise, and interview answers

First time writing Python?Start from zero →Read the punctuation guide ↗

The idea

SQLite provides a small relational database through Python’s standard library. Use parameter placeholders for values, commit writes deliberately, and close the connection. An in-memory database is handy for isolated exercises.

A complete program to try.

BEFORE YOU RUN

Save the entire program in sqlite_and_parameterized_sql.py. Open a terminal in that file’s folder and activate your project’s virtual environment. Commands go in the terminal; the program goes in the .py file.

This program uses only Python’s standard library; no extra package is needed.

Run: python sqlite_and_parameterized_sql.py

On macOS/Linux outside a virtual environment use python3; on Windows use py. The beginner guide explains both.

sqlite_and_parameterized_sql.pyDownload program ↓
COMPLETE PYTHON PROGRAM
import sqlite3
with sqlite3.connect(":memory:") as database:
    database.execute("CREATE TABLE results (name TEXT, passed INTEGER)")
    database.execute("INSERT INTO results VALUES (?, ?)", ("login", 1))
    rows = database.execute("SELECT name FROM results WHERE passed = ?", (1,)).fetchall()
    print(rows)
database.close()
EXPECTED RESULT
[('login',)]

TRICKY PYTHON PROGRAM
import sqlite3
with sqlite3.connect(":memory:") as database:
    database.execute("CREATE TABLE users (name TEXT)")
    database.execute("INSERT INTO users VALUES (?)", ("Mira",))
    value = "Mira' OR '1'='1"
    rows = database.execute("SELECT name FROM users WHERE name = ?", (value,)).fetchall()
    print(rows)
database.close()

Run: python tricky_sqlite_and_parameterized_sql.py

The suspicious text is treated as one literal name, not as an OR expression, so it matches no stored record.

INTERVIEW PRACTICE · EXPLAIN THE WHY

Talk it through.

Answer in your own words first. Then check the explanation and connect it to the programs above.

Do parameter placeholders prevent every kind of SQL problem?

They safely represent data values without treating them as query syntax. They do not parameterize identifiers such as table names and cannot replace authorization or validation of query structure.

Which common mistake can affect this program or test?

String interpolation into SQL can alter query meaning. Connection context management commits or rolls back; it does not itself close the connection.
