Selenium windows and tabs

Interactions · Complete program, tricky exercise, and interview answers

The idea

Store the original window handle and identify a new handle by set difference. Switch deliberately, verify the target, and restore the original context after closing. Handle order should not be your only identifier.

A complete program to try.

BEFORE YOU RUN

Save the entire program in test_selenium_windows_and_tabs.py. Open a terminal in that file’s folder and activate your project’s virtual environment. Commands go in the terminal; the program goes in the .py file.

Install once in your activated environment: python -m pip install pytest selenium.

The Way2Python site must be running at localhost:8080/way2python. Selenium also needs an installed browser such as Chrome.

Run: python -m pytest test_selenium_windows_and_tabs.py -q

On macOS/Linux outside a virtual environment use python3; on Windows use py. The beginner guide explains both.

COMPLETE PYTHON PROGRAM
import os
import pytest
from selenium import webdriver
from selenium.webdriver.common.by import By
from selenium.webdriver.support.ui import WebDriverWait
from selenium.webdriver.support import expected_conditions as EC

@pytest.fixture
def driver():
    instance = webdriver.Chrome()
    yield instance
    instance.quit()

def test_practice(driver):
    base_url = os.getenv("WAY2PYTHON_URL", "http://localhost:8080/way2python")
    driver.get(f"{base_url}/practice.html")
    original = driver.current_window_handle
    before = set(driver.window_handles)
    driver.find_element(By.ID, "open-window").click()
    WebDriverWait(driver, 5).until(EC.number_of_windows_to_be(2))
    new_handle = (set(driver.window_handles) - before).pop()
    driver.switch_to.window(new_handle)
    assert driver.find_element(By.TAG_NAME, "h1").text == "Practice window"
    driver.close()
    driver.switch_to.window(original)
EXPECTED RESULT
1 passed; the new window is checked and closed.

INTERVIEW PRACTICE · EXPLAIN THE WHY

Talk it through.

Answer in your own words first. Then check the explanation and connect it to the programs above.

Why identify a new window by handle difference rather than assuming handle index 1?

The difference states which handle appeared after the action. A positional assumption depends on existing windows and order. Verify the target document and switch back to a surviving original handle after closing.

Which common mistake can affect this program or test?

After closing a window, switch to a surviving handle before another browser command.
