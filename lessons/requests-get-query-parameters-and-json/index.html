Requests: GET, query parameters and JSON

HTTP & clients · Complete program, tricky exercise, and interview answers

First time writing Python?Start from zero →Read the punctuation guide ↗

The idea

Requests provides an approachable synchronous HTTP client. Pass query parameters through params and parse the response with json(). The local API returns an items list and a total count; limit bounds how many records are returned.

A complete program to try.

BEFORE YOU RUN

Save the entire program in requests_get_query_parameters_and_json.py. Open a terminal in that file’s folder and activate your project’s virtual environment. Commands go in the terminal; the program goes in the .py file.

Install once in your activated environment: python -m pip install requests.

Start the local API service first: python mock_api.py --port 8765 from the unzipped practice kit. Keep that terminal running, and run the program in a second activated terminal.

Run: python requests_get_query_parameters_and_json.py

On macOS/Linux outside a virtual environment use python3; on Windows use py. The beginner guide explains both.

COMPLETE PYTHON PROGRAM
import requests
response = requests.get("http://127.0.0.1:8765/users",
    headers={"Authorization": "Bearer demo-token"},
    params={"limit": 2}, timeout=5)
assert response.status_code == 200
data = response.json()
assert isinstance(data["items"], list)
assert len(data["items"]) <= 2
print("List contract passed")
EXPECTED RESULT
List contract passed.

INTERVIEW PRACTICE · EXPLAIN THE WHY

Talk it through.

Answer in your own words first. Then check the explanation and connect it to the programs above.

Does parsing response JSON guarantee that each field has the type your API promises?

No. It parses the JSON types actually sent. A service can send text instead of a numeric ID or boolean. Validate schema and required values rather than coercing incorrect responses into passing results.

Which common mistake can affect this program or test?

json() can fail if the body is not JSON. Check the response type and use useful failure diagnostics.
