NumPy boolean masks and missing numerical values

NumPy foundations · Complete program, tricky exercise, and interview answers

First time writing Python?Start from zero →Read the punctuation guide ↗

The idea

Boolean masks select values that satisfy a condition. Floating-point NaN represents a missing or undefined numerical value and has special comparison behavior. Decide whether missing data should be rejected, ignored, or imputed.

A complete program to try.

Save the entire program in numpy_boolean_masks_and_missing_numerical_values.py. Open a terminal in that file’s folder and activate your project’s virtual environment. Commands go in the terminal; the program goes in the .py file.

Install once in your activated environment: python -m pip install numpy.

COMPLETE PYTHON PROGRAM
import numpy as np
durations = np.array([0.2, np.nan, 1.4, 0.5])
valid = durations[~np.isnan(durations)]
print(valid[valid > 0.4].tolist())
print(round(float(np.nanmean(durations)), 2))
EXPECTED RESULT
[1.4, 0.5]
0.7

Talk it through.

Answer in your own words first. Then check the explanation and connect it to the programs above.

Why is equality with NaN unsuitable for finding missing values?

NaN compares unequal even to itself. Use np.isnan for numerical arrays and report missingness deliberately. A nan-ignoring aggregation can be useful, but it must not conceal a data-collection problem.

Which common mistake can affect this program or test?

NaN is not equal to itself. Use np.isnan(), and do not suppress missingness without understanding its cause.
