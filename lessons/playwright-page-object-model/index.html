Playwright page object model

Framework & CI · Complete program, tricky exercise, and interview answers

First time writing Python?Start from zero →Read the punctuation guide ↗

The idea

A page object gives names to meaningful UI actions and locators. Keep its methods narrow and leave scenario expectations visible in the test. Pass the existing page into the object so the fixture retains lifecycle ownership.

A complete program to try.

BEFORE YOU RUN

Save the entire program in test_playwright_page_object_model.py. Open a terminal in that file’s folder and activate your project’s virtual environment. Commands go in the terminal; the program goes in the .py file.

Install once in your activated environment: python -m pip install pytest-playwright.

Install Chromium once: python -m playwright install chromium. Browser test files use fixtures supplied by the pytest plugin.

The Way2Python site must be running at localhost:8080/way2python. Selenium also needs an installed browser such as Chrome.

Run: python -m pytest test_playwright_page_object_model.py -q --base-url http://localhost:8080/way2python

On macOS/Linux outside a virtual environment use python3; on Windows use py. The beginner guide explains both.

COMPLETE PYTHON PROGRAM
from playwright.sync_api import expect
class LoginPage:
    def __init__(self, page):
        self.page = page
    def sign_in(self, email, password):
        self.page.get_by_label("Email", exact=True).fill(email)
        self.page.get_by_label("Password", exact=True).fill(password)
        self.page.get_by_role("button", name="Sign in", exact=True).click()

def test_login(page, base_url):
    page.goto(f"{base_url}/practice.html")
    LoginPage(page).sign_in("learner@example.test", "python123")
    expect(page.get_by_test_id("login-status")).to_have_text("Welcome, learner!")
EXPECTED RESULT
1 passed with pytest-playwright and the local site base URL.

Read it step by step.

Read from the top. A function or class body does not run just because you defined it; look for the call, or let pytest call a test function.

  1. Line 1: Import playwright.sync_api. This makes the named library tools available; third-party packages must be installed first.
  2. Line 2: Define the class LoginPage. It groups related data and methods; constructing an instance and calling methods happens later.
  3. Line 10: Define test_login(page, base_url). Its body runs when called by pytest, which supplies fixture arguments.
  4. Line 11: Navigate the browser to the indicated application page. The target site must be running and reachable.
  5. Line 12: Call LoginPage(page).sign_in with the shown arguments. Read its result contract before assuming a successful call means the behavior was correct.
  6. Line 13: Check the browser’s observable state with a retrying Playwright expectation. It must become correct before the timeout.

Answer in your own words first. Then check the explanation and connect it to the programs above.

What belongs in a page object and what belongs in the test?

Page objects name relevant locators and UI operations; fixtures own lifecycle; tests state scenario and business expectations. Several components may receive the same page within one scenario without creating another browser.

Which common mistake can affect this program or test?

A page object should not create a second browser unless that is its explicit responsibility.
