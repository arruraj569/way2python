CODING EXERCISE 02

Check a normalized palindrome

Ignore spaces and punctuation and compare text without case differences. State this normalization rule before coding.

Reveal the complete solution and explanation
palindrome.pyDownload program ↓
COMPLETE PYTHON PROGRAM
def palindrome(text):
    normalized = "".join(character for character in text.casefold() if character.isalnum())
    return normalized == normalized[::-1]

print(palindrome("Never odd or even"))
print(palindrome("Python"))

Run: python palindrome.py

EXPECTED OUTPUT
True
False

casefold handles case normalization, isalnum selects letters/digits, and comparison with the reverse checks the rule. Empty normalized input is true under this definition.

Complexity: O(n) time and O(n) extra space.

Interview follow-up

Use two pointers on the original string, then discuss whether Unicode normalization changes your assumptions.

CODING EXERCISE 03

Check whether two texts are anagrams

Compare the frequency of each normalized letter. Here whitespace and punctuation are ignored.

Reveal the complete solution and explanation
anagram.pyDownload program ↓
COMPLETE PYTHON PROGRAM
from collections import Counter
def letters(text):
    return Counter(character for character in text.casefold() if character.isalpha())
def anagrams(first, second):
    return letters(first) == letters(second)

print(anagrams("Listen", "Silent"))
print(anagrams("hello", "world"))

Run: python anagram.py

EXPECTED OUTPUT
True
False

Counter stores the occurrence count for each character. Equality checks both which characters occur and how many times they occur.

Complexity: Expected O(n + m) time and O(k) counter space, where k is the number of distinct characters.

Interview follow-up

Explain why comparing only sets would incorrectly accept some repeated-letter inputs.

CODING EXERCISE 04

Count word frequencies

Split whitespace-separated text, ignore case, and produce a count per word. Punctuation is retained in this simple tokenizer.

Reveal the complete solution and explanation
word_frequency.pyDownload program ↓
COMPLETE PYTHON PROGRAM
def frequencies(text):
    counts = {}
    for word in text.casefold().split():
        counts[word] = counts.get(word, 0) + 1
    return counts

print(frequencies("api UI api"))

Run: python word_frequency.py

EXPECTED OUTPUT
{'api': 2, 'ui': 1}

get supplies zero for the first occurrence. Later occurrences increment the same word’s count. State your tokenization assumptions before extending the code.

Complexity: Expected O(n) processing time and O(k) count space.

Interview follow-up

Adapt the result to report the three most common failure terms with a deterministic tie-breaker.

CODING EXERCISE 05

Remove duplicates and preserve order

Keep the first appearance of each hashable value rather than sorting the input or losing its order.

Reveal the complete solution and explanation
remove_duplicates.pyDownload program ↓
COMPLETE PYTHON PROGRAM
def unique_in_order(values):
    seen, result = set(), []
    for value in values:
        if value not in seen:
            seen.add(value)
            result.append(value)
    return result

print(unique_in_order([3, 1, 3, 2, 1]))

Run: python remove_duplicates.py

EXPECTED OUTPUT
[3, 1, 2]

The set handles membership; the list records first appearances. The input is not modified. The values must support hashing.

Complexity: Expected O(n) time and O(k) extra space.

Interview follow-up

Handle dictionaries by a declared key such as user ID instead of trying to put the whole dictionary in a set.

CODING EXERCISE 06

Find the first non-repeating character

Return the earliest character whose count is one, or None if no such character exists.

Reveal the complete solution and explanation
first_nonrepeating.pyDownload program ↓
COMPLETE PYTHON PROGRAM
from collections import Counter
def first_unique(text):
    counts = Counter(text)
    return next((character for character in text if counts[character] == 1), None)

print(first_unique("swiss"))
print(first_unique("aabb"))

Run: python first_nonrepeating.py

EXPECTED OUTPUT
w
None

The first pass counts; the second preserves the text’s original order. A default on next provides a defined result for the no-match case.

Complexity: Expected O(n) time and O(k) counter space.

Interview follow-up

Decide whether uppercase and lowercase characters should be counted together and test that rule.

CODING EXERCISE 07

Generate the first n Fibonacci values

Use iteration to generate a sequence starting with 0 and 1. Reject negative or non-integer lengths.

Reveal the complete solution and explanation
fibonacci.pyDownload program ↓
COMPLETE PYTHON PROGRAM
def fibonacci(length):
    if type(length) is not int or length < 0:
        raise ValueError("length must be a nonnegative integer")
    first, second = 0, 1
    result = []
    for _ in range(length):
        result.append(first)
        first, second = second, first + second
    return result

print(fibonacci(8))
print(fibonacci(0))

Run: python fibonacci.py

EXPECTED OUTPUT
[0, 1, 1, 2, 3, 5, 8, 13]
[]

The tuple assignment uses the previous pair to compute the next pair before changing either name. Exact int checking deliberately rejects booleans.

Complexity: O(n) iterations and O(n) result space, ignoring growing integer bit-cost.

Interview follow-up

Write a generator yielding values one at a time and compare its memory use.

CODING EXERCISE 08

Test a number for primality

For an integer, return whether it has no divisors other than 1 and itself. Handle values below 2.

Reveal the complete solution and explanation
prime_number.pyDownload program ↓
COMPLETE PYTHON PROGRAM
from math import isqrt
def is_prime(number):
    if number < 2:
        return False
    for divisor in range(2, isqrt(number) + 1):
        if number % divisor == 0:
            return False
    return True

print(is_prime(29), is_prime(25), is_prime(1))

Run: python prime_number.py

EXPECTED OUTPUT
True False False

A composite integer has a divisor at or below its square root. Including the endpoint is necessary to reject perfect squares.

Complexity: O(√n) trial divisions and O(1) extra space, treating arithmetic operations as constant cost.

Interview follow-up

Skip even candidate divisors after separately handling two; test perfect squares.

CODING EXERCISE 09

Calculate factorial with input validation

Return n! for an exact nonnegative integer; explain why 0! is one and why bool requires a deliberate decision.

Reveal the complete solution and explanation
factorial.pyDownload program ↓
COMPLETE PYTHON PROGRAM
def factorial(number):
    if type(number) is not int or number < 0:
        raise ValueError("use a nonnegative integer")
    result = 1
    for value in range(2, number + 1):
        result *= value
    return result

print(factorial(0), factorial(5))

Run: python factorial.py

EXPECTED OUTPUT
1 120

Start with the multiplication identity one and include number in the range. Exact integer validation rejects booleans as well as fractional and negative inputs.

Complexity: O(n) multiplications and one accumulator, ignoring growing integer bit-cost.

Interview follow-up

Compare the iterative and recursive implementations, including their stack use and invalid inputs.

CODING EXERCISE 10

Find two indices whose values sum to a target

Return two different indices, including when equal values occur at different positions. Return None if no pair exists.

Reveal the complete solution and explanation
two_sum.pyDownload program ↓

def two_sum(values, target):
    seen = {}
    for index, value in enumerate(values):
        needed = target - value
        if needed in seen:
            return seen[needed], index
        seen[value] = index
    return None

print(two_sum([2, 7, 11, 15], 9))
print(two_sum([3, 3], 6))
print(two_sum([3], 6))

Run: python two_sum.py

EXPECTED OUTPUT
(0, 1)
(0, 1)
None

Check for the complement before storing the current index so a value cannot pair with itself. Earlier duplicates remain eligible as different indices.

Complexity: Expected O(n) time and O(n) dictionary space.

Interview follow-up

Return every unique value pair and explain how that changes duplicate handling.

CODING EXERCISE 11

Find the second-largest distinct value

Find the second-largest distinct integer without sorting. Return None if there are fewer than two distinct values.

Reveal the complete solution and explanation
second_largest.pyDownload program ↓
COMPLETE PYTHON PROGRAM
def second_largest(values):
    largest = second = None
    for value in values:
        if largest is None or value > largest:
            second, largest = largest, value
        elif value != largest and (second is None or value > second):
            second = value
    return second

print(second_largest([5, 5, 3, 2]))
print(second_largest([-4, -2, -3]))
print(second_largest([5, 5]))

Run: python second_largest.py

EXPECTED OUTPUT
3
-3
None

Track two distinct candidates and exclude values equal to the current maximum. None avoids inventing an unsuitable zero sentinel for negative inputs.

Complexity: O(n) time and O(1) auxiliary space.

Interview follow-up

Clarify whether second-largest means distinct value or second position after sorting; they differ for duplicates.

CODING EXERCISE 12

Flatten nested lists

Return leaf values in order from nested Python lists. Other types, including tuples, are treated as leaf values by this contract.

Reveal the complete solution and explanation
flatten_nested_list.pyDownload program ↓
COMPLETE PYTHON PROGRAM
def flatten(values):
    result = []
    def visit(items):
        for item in items:
            if isinstance(item, list):
                visit(item)
            else:
                result.append(item)
    visit(values)
    return result

print(flatten([1, [2, [3], []], 4]))

Run: python flatten_nested_list.py

EXPECTED OUTPUT
[1, 2, 3, 4]

The recursive helper traverses each list and appends leaves to one shared result, avoiding repeated concatenation of intermediate results. Very deep nesting can exceed recursion limits.

Complexity: O(n) visited nodes and O(d) call-stack depth, plus the output list.

Interview follow-up

Replace recursion with an explicit stack while preserving order; handle cyclic input as a separate contract decision.

CODING EXERCISE 13

Search a sorted sequence with binary search

Return an index for the target in an ascending sorted sequence, or None. This program can return any matching index for duplicates.

Reveal the complete solution and explanation
binary_search.pyDownload program ↓
COMPLETE PYTHON PROGRAM
def binary_search(values, target):
    low, high = 0, len(values) - 1
    while low <= high:
        middle = (low + high) // 2
        if values[middle] == target:
            return middle
        if values[middle] < target:
            low = middle + 1
        else:
            high = middle - 1
    return None

print(binary_search([1, 3, 5, 7, 9], 7))
print(binary_search([1, 3, 5, 7, 9], 4))

Run: python binary_search.py

EXPECTED OUTPUT
3
None

Each comparison removes roughly half the remaining search interval. Moving past middle is essential so an unsuccessful iteration still makes progress.

Complexity: O(log n) comparisons and O(1) auxiliary space for a random-access sequence.

Interview follow-up

Adapt the algorithm to return the first matching index when duplicates are present.

CODING EXERCISE 14

Check balanced brackets with a stack

Validate nesting of (), [] and {} in a raw character sequence. Non-bracket characters are ignored; this is not a full programming-language parser.

Reveal the complete solution and explanation
balanced_brackets.pyDownload program ↓
COMPLETE PYTHON PROGRAM
def balanced(text):
    expected = {")": "(", "]": "[", "}": "{"}
    stack = []
    for character in text:
        if character in expected.values():
            stack.append(character)
        elif character in expected:
            if not stack or stack.pop() != expected[character]:
                return False
    return not stack

print(balanced("{[()]}"))
print(balanced("([)]"))
print(balanced("(("))

Run: python balanced_brackets.py

EXPECTED OUTPUT
True
False
False

The most recent opening bracket must match the next closing bracket. An empty stack handles excess closes, and the final emptiness check handles excess opens.

Complexity: O(n) time and O(n) worst-case stack space.

Interview follow-up

Return the first error position rather than just a boolean, with a defined result for leftover opening brackets.

CODING EXERCISE 15

Find one missing number from 0 through n

The input has n distinct integers from 0 through n, with exactly one absent value. State these assumptions: the sum trick alone does not validate them.

Reveal the complete solution and explanation
missing_number.pyDownload program ↓
COMPLETE PYTHON PROGRAM
def missing_number(values):
    number = len(values)
    expected_total = number * (number + 1) // 2
    return expected_total - sum(values)

print(missing_number([0, 1, 3, 4]))
print(missing_number([]))

Run: python missing_number.py

EXPECTED OUTPUT
2
0

The complete sequence’s sum minus the supplied sum is the missing value only under the stated uniqueness/range contract. Empty input means zero is missing from the range containing only zero.

Complexity: O(n) summation time and O(1) auxiliary space, ignoring integer bit-cost.

Interview follow-up

Add explicit range and uniqueness validation and discuss its additional memory cost.

CODING EXERCISE 16

Merge two sorted lists with two pointers

Combine two ascending sorted lists into a new ascending list while retaining duplicate values.

Reveal the complete solution and explanation
merge_sorted.pyDownload program ↓
COMPLETE PYTHON PROGRAM
def merge_sorted(left, right):
    first = second = 0
    result = []
    while first < len(left) and second < len(right):
        if left[first] <= right[second]:
            result.append(left[first])
            first += 1
        else:
            result.append(right[second])
            second += 1
    result.extend(left[first:])
    result.extend(right[second:])
    return result

print(merge_sorted([1, 3, 5], [2, 4]))
print(merge_sorted([], [1, 1]))

Run: python merge_sorted.py

EXPECTED OUTPUT
[1, 2, 3, 4, 5]
[1, 1]

Each pointer advances only through its own list. When one side is exhausted, append the remaining sorted tail. The input lists remain unchanged.

Complexity: O(n + m) time and O(n + m) result space.

Interview follow-up

Explain why sorting the concatenation is simpler but has a different general time bound.
