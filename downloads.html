1. Prepare your environment

Unzip the kit, open its folder, and create a virtual environment. Use Python 3.12 or newer.

MACOS / LINUX
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python -m playwright install chromium

Windows PowerShell: use py -m venv .venv and .venv\Scripts\Activate.ps1. A browser must also be installed for Selenium.

2. Try the browser lab

The Way2Python site must be running. Both suites use the same local practice page.

TESTS
python -m pytest test_playwright_lab.py --base-url http://localhost:8080/way2python
python -m pytest test_selenium_lab.py
Open the practice lab →

3. Test a local API

Start the service in one terminal and tests in another. It listens on 127.0.0.1:8765 and keeps records in memory.

TWO TERMINALS
python mock_api.py --port 8765
# In a second terminal:
python -m pytest test_api_lab.py -q

Contract: Bearer demo-token for /users; 201 create, 200 read/update, 204 delete, 401 unauthorized, 404 missing, 409 duplicate, 422 invalid.

4. Inspect your data

Run a small NumPy and pandas example that summarizes test durations and failures.

PYTHON
python analyze_results.py

Extend it to load real exported test results, then add a chart or a reviewed failure-classification baseline.
