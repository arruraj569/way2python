Your first line of Python.
Let’s begin at zero.

You do not need to know a programming language. A program is a set of instructions; Python is the language we use to write them. Start with a tiny working program and build one idea at a time.

What you need

A computer, a text editor, and Python 3.12 or newer. A terminal runs commands. An editor saves your code in a file. The Python interpreter reads the file and carries out its instructions. This website explains code; you run programs on your computer.

Official Python downloads ↗Detailed setup lesson →
01

Install and check Python.

Install Python from the official website. On Windows, enable the installer’s PATH option if offered. Open Terminal on macOS/Linux or PowerShell on Windows. Type one of these commands and press Enter.

macOS / Linux

TERMINAL COMMAND
python3 --version

Windows

POWERSHELL COMMAND
py --version

You should see a Python 3 version. If the command is not found, complete the installation or check your interpreter path before going further.

02

Save your first program.

Create a folder called python-practice. Open it in an editor and save a plain-text file named hello.py containing this code. The .py extension tells you it is a Python source file.

PYTHON · HELLO.PY
name = "Learner"
print("Hello,", name)
print(2 + 3)
  1. name is a variable: a name for a value. The quoted text is a string.
  2. print() displays values in the terminal. The parentheses contain its inputs.
  3. 2 + 3 is arithmetic. Python computes it before print displays the result.

In your terminal, change into the folder you created. Run python3 hello.py on macOS/Linux or py hello.py on Windows.

EXPECTED OUTPUT
Hello, Learner
5

Change Learner to your name, save the file, and run it again. Saving and running are separate actions.

03

Read Python’s basic punctuation.

"text" or 'text'
A string: text between matching quotation marks.
= and ==
One equals sign assigns a value to a name. Two compare values for equality.
# comment
A note for people reading the code. Python ignores the comment.
True, False, None
Boolean yes/no values and a value meaning no result or missing value. Capitalization matters.
[] and {}
Lists contain ordered items. Dictionaries connect keys to values. A nonempty brace expression can also define a set.
: and indentation
A colon often begins a block after if, for, def or class. Indent its body consistently, normally with four spaces.
def, parameters, return
def defines a reusable function. Parameters name its inputs; return sends a result back to the caller.
import and a package
import makes a module available. Standard-library modules come with Python; third-party packages need installation.
assert and an exception
assert checks an expectation. If it fails, Python raises an error with information about where it happened.
04

Understand a small function.

PYTHON
def add_numbers(first, second):
    result = first + second
    return result

answer = add_numbers(2, 3)
print(answer)
assert answer == 5
  1. def creates a function called add_numbers with two inputs.
  2. The indented body adds those inputs and returns the result.
  3. The call supplies 2 and 3; answer receives the returned 5.
  4. print shows it; assert checks that it matches the expected value.

Change the assertion’s expected value to 6. Read the resulting AssertionError, then restore 5. An intentional error is useful practice.

05

Separate Python, terminal commands, and tests.

A Python program goes in a .py file. Commands such as python -m pip install pytest go in the terminal. Do not paste a shell command into a Python file or type output lines as code. A pytest file normally has a test_ name and is run by pytest, which calls its test functions.

MACOS / LINUX · NEW PROJECT ENVIRONMENT
python3 -m venv .venv
source .venv/bin/activate
python -m pip install pytest
python -m pytest test_example.py

On Windows, create with py -m venv .venv and activate with .venv\Scripts\Activate.ps1. The pytest command requires a saved test_example.py. The practice kit contains complete test files and step-by-step setup instructions.

When something goes wrong

Read the last error line and the file/line number. NameError means a name is unavailable; TypeError often means the operation received an unsuitable type; IndentationError means the block spacing is wrong; ModuleNotFoundError usually means a missing package or a different environment. Reproduce the smallest failing input and inspect both value and type.
